# 手動操作（自操作）攻略

## 可選的比賽玩法

KONAMI 官方確認，2026 版榮冠九人（栄冠ナイン）可以在遊戲設定（ゲーム設定）選擇三種比賽玩法：[KONAMI](https://www.konami.com/pawa/2026-2027/mode/eikan)

| 玩法 | 說明 |
|---|---|
| 戰術比賽（戦術試合） | 傳統監督玩法，以戰術指示進行比賽。 |
| 全隊操作（チームプレイ） | 在原本出現指示機會的場合，自行操作投球、守備、跑壘與打擊。 |
| 扮演操作（なりきりプレイ） | 比賽前選擇焦點球員（注目選手），比賽中只操作該球員。 |

全隊操作（チームプレイ）與扮演操作（なりきりプレイ）的操作範圍由 [AppMedia](https://appmedia.jp/pawapuro2026-2027/80107618) 整理。

## 與戰術比賽的差異

- 手動操作（自操作）不能使用戰術卡（戦術カード）。
- 魔物（魔物）、祭典男（お祭り男）等固有戰術（固有戦術）也不能使用。
- 傳令（伝令）仍然可以使用；AppMedia 特別建議善用恢復先發投手體力的鼓勵類傳令（励ます系の伝令）。

來源：[AppMedia：手動操作的方法與注意事項](https://appmedia.jp/pawapuro2026-2027/80107618)

## 建議設定

以下是 AppMedia 的攻略建議，不是官方強制設定：[AppMedia：推薦遊戲設定](https://appmedia.jp/pawapuro2026-2027/80107777)

- 想玩手動操作時，把比賽玩法（試合のプレイスタイル）從戰術比賽（戦術試合）改為全隊操作（チームプレイ）或扮演操作（なりきりプレイ）。
- 自動換人（自動交代）建議設為「無（なし）」，避免系統提前換掉預定使用的投手或野手。
- 操作機會（操作機会）可先設為「普通（ふつう）」，再依自己的守備風險與操作熟練度調整。
- 高速比賽切換（高速試合への遷移）可設為「10 分差（10点差）」或「無（なし）」，保留更多手動打擊機會；若手動守備容易失分，則應依能力調整。

## 與覺醒的關係

覺醒（覚醒）由目前攻略來源記錄為日程推進時自動發生的事件，手動操作（自操作）則是比賽玩法選項。現有來源沒有記錄兩者存在機率連動，也沒有證據顯示改成手動操作會停用覺醒。[Game8](https://game8.jp/eikan-nine/554832)／[KONAMI](https://www.konami.com/pawa/2026-2027/mode/eikan)
