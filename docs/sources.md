## 使用原則

1. 涉及遊戲規格、模式功能、更新內容或產品資訊時，優先引用 KONAMI 官方資料。
2. 官方未公開的機率、能力變化或內部規則，優先尋找有方法、樣本與結果的日文實測資料，並清楚標示為實測結論，而非官方規格。
3. Game8 與 AppMedia 適合用於查找攻略主題、比較整理結果及交叉核對；重要數值不應只因單一攻略站刊載便視為已確認。
4. 引用前必須重新開啟頁面，確認內容仍存在、對應目前遊戲版本，並記錄實際使用的頁面，而非只引用網站首頁。
5. 若來源互相衝突，文件必須列出差異、版本與採用理由，不可隱藏衝突。
